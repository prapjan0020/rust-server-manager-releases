# Rust Server Manager

โปรแกรมจัดการเซิฟเวอร์ Rust แบบมีหน้าจอ สำหรับ Windows — เปิด/ปิดเซิฟเวอร์, ตั้งค่าอัตราคูณ,
เสกไอเทม, จัดการปลั๊กอิน Oxide, สำรองข้อมูลแมพ, ตั้งแอดมิน และมีเทอมินอลในตัว ไม่ต้องพิมพ์คำสั่ง
เองเลยแม้แต่บรรทัดเดียว

> 📦 repo นี้เก็บเฉพาะตัวติดตั้ง (.exe) ไม่มีซอร์สโค้ด

## ดาวน์โหลด

ไปที่แท็บ **[Releases](../../releases/latest)** ด้านขวามือ แล้วโหลดไฟล์
`Rust Server Manager Setup x.x.x.exe` ตัวล่าสุด

## สเปกเครื่องที่ต้องมี

- **Windows 10/11 (64-bit)** เท่านั้น — ใช้กับ Mac/Linux ไม่ได้
- พื้นที่ว่างอย่างน้อย **10 GB** (ไฟล์เกม Rust + SteamCMD รวมกัน ~6-8 GB)
- อินเทอร์เน็ตสำหรับดาวน์โหลดไฟล์เกมครั้งแรก และทุกครั้งที่ Rust อัปเดตเวอร์ชัน
- แรม 8 GB ขึ้นไปแนะนำ (เซิฟเวอร์ Rust กินแรมค่อนข้างเยอะตอนสร้างแผนที่)

## วิธีติดตั้ง

1. ดับเบิลคลิกไฟล์ `.exe` ที่โหลดมา
2. Windows จะขึ้นเตือน **"Windows protected your PC"** — เป็นเรื่องปกติ ไม่ใช่ไฟล์เสีย
   (โปรแกรมนี้เซ็นด้วย self-signed certificate ยังไม่ได้ซื้อใบรับรองแบบเชื่อถือสาธารณะจาก CA)
   กด **"More info"** แล้วกด **"Run anyway"**
3. เลือกโฟลเดอร์ติดตั้ง (ค่าเริ่มต้นก็ได้) → ติ๊กสร้าง shortcut บน Desktop/Start Menu ตามชอบ →
   กด Install
4. เปิดโปรแกรมจาก shortcut ที่สร้างไว้

## เริ่มใช้งานครั้งแรก

1. **กดปุ่ม "ติดตั้ง/อัปเดต"** ที่มุมขวาบน — โปรแกรมจะดาวน์โหลด SteamCMD และไฟล์เกม Rust ให้
   อัตโนมัติ (~6 GB ใช้เวลา 5-15 นาทีขึ้นกับความเร็วเน็ต) ดูความคืบหน้าได้ที่กล่องคอนโซลตรงกลาง
2. **ไปแท็บ "จัดการแอดมิน & สิทธิ์"** ใส่ SteamID64 ของตัวเอง (ตัวเลข 17 หลัก หาได้จาก
   [steamid.io](https://steamid.io)) แล้วกด **"แต่งตั้งเป็น Admin"** — ขั้นตอนนี้สำคัญมาก
   ถ้าข้ามไปจะสั่งคำสั่งแอดมินในเกมไม่ได้เลย
3. **กด "เริ่มเซิฟเวอร์"** ที่มุมขวาบน รอจนสถานะขึ้น **"พร้อมให้เข้าเล่น"** (ครั้งแรกช้ากว่าปกติ
   เพราะต้องสร้างแผนที่ใหม่ทั้งหมด อาจใช้เวลา 1-3 นาที)
4. เปิดเกม Rust → กด **F1** → พิมพ์คำสั่งที่หน้าแรกของโปรแกรมโชว์ไว้ (เช่น
   `client.connect 127.0.0.1:28015` ถ้าเล่นเองในเครื่อง)

## ฟีเจอร์ทั้งหมด

### 📊 หน้าแรก & คอนโซล
ภาพรวมเซิฟเวอร์ทั้งหมดในหน้าเดียว — สถานะทำงาน, จำนวนผู้เล่นออนไลน์, สถานะ RCON, คำสั่ง
`client.connect` แบบพร้อมกดคัดลอก (มีทั้งแบบเล่นเอง/แบบ LAN/แบบ Public IP) และคอนโซล realtime
ที่เห็น log ของเซิฟเวอร์สด ๆ พร้อมช่องพิมพ์คำสั่ง RCON เองได้โดยตรง

### ⚡ อัตราคูณ & การดรอป
ปรับอัตราการเก็บทรัพยากร, อัตราดรอปไอเทม, ตัวคูณ stack, ความเร็วคราฟต์/หลอมแร่ และความยาว
กลางวัน-กลางคืน ด้วย slider มีพรีเซ็ตสำเร็จรูปให้กด (Vanilla, x2, x5, x10) หรือปรับเองแบบละเอียด
บันทึกแล้วมีผลทันทีโดยไม่ต้องรีสตาร์ทเซิฟเวอร์

### 🧩 ปลั๊กอิน Oxide
เรียกดูรายการปลั๊กอิน Oxide/uMod ยอดนิยม กดติดตั้ง/ถอนได้ในคลิกเดียว ไม่ต้องหาไฟล์ .cs มาวางเอง

### 🎁 ระบบเสกของ
คลังไอเทมกว่า 89 รายการ แบ่งหมวดชัดเจน (อาวุธ, กระสุน, เกราะ, ทรัพยากร, อาหาร/ยา,
เครื่องมือ/ยานพาหนะ, สิ่งก่อสร้าง) ใส่ SteamID64 หรือชื่อผู้เล่นที่ออนไลน์อยู่ กดเสกได้เลย
ระบบเช็คให้อัตโนมัติว่าผู้เล่นออนไลน์จริงก่อนส่ง กันเสกพลาดไปที่ไม่มีใครรับ

### 💾 สำรองข้อมูลแมพ
สร้าง/กู้คืน/ลบไฟล์สำรองแผนที่ได้จากหน้าโปรแกรมโดยตรง กันแมพพังหรืออยากย้อนกลับไปจุดก่อนหน้า

### 👑 จัดการแอดมิน & สิทธิ์
เพิ่ม/ลบแอดมินด้วย SteamID64 พร้อมปุ่มลัดคำสั่งแอดมินที่ใช้บ่อย (God Mode, โหมดบิน, ปรับเวลา
เที่ยงวัน ฯลฯ)

### 🛡️ ระบบกู้คืนอัตโนมัติ
เปิดไว้แล้วถ้าเซิฟเวอร์ล่มกลางคัน โปรแกรมจะรีสตาร์ทให้อัตโนมัติโดยไม่ต้องมานั่งเฝ้า

### ⚙️ ตั้งค่าเซิฟเวอร์
ชื่อเซิฟเวอร์, คำอธิบาย, จำนวนผู้เล่นสูงสุด, ขนาดแผนที่, Seed, รหัสผ่าน RCON — ปรับได้ทั้งหมด
ในหน้าเดียว (รหัส RCON สุ่มใหม่ให้อัตโนมัติตั้งแต่ติดตั้งครั้งแรก ไม่ต้องตั้งเอง)

### 💻 เทอมินอล
เทอมินอลของเครื่องจริง (cmd.exe) ฝังอยู่ในโปรแกรม เปิดเป็นหน้าต่างแยกได้ทันทีโดยไม่ต้องออกไป
เปิด Command Prompt เอง — รันคำสั่งทั่วไปได้ (`dir`, `git`, `npm` ฯลฯ) เข้าถึงได้เฉพาะจากเครื่อง
ที่รันโปรแกรมอยู่เท่านั้น เข้าจากเครื่องอื่นในวงแลนไม่ได้

## ให้เพื่อนเข้าเล่นจากนอกบ้าน

ต้อง forward พอร์ตที่เราเตอร์ (หน้าตั้งค่าเราเตอร์แต่ละยี่ห้อไม่เหมือนกัน ค้นหา "port forwarding"
ตามรุ่นเราเตอร์ของตัวเอง):

| พอร์ต | โปรโตคอล | จำเป็นไหม |
|---|---|---|
| 28015 | UDP | ✅ จำเป็น — พอร์ตเกม |
| 28016 | TCP | ⚠️ เปิดเฉพาะถ้าต้องการจัดการ RCON จากนอกบ้าน (ไม่แนะนำถ้าไม่จำเป็นจริง ๆ) |

เพื่อนใช้คำสั่ง `client.connect <Public-IP-ของคุณ>:28015` (ดู Public IP ได้ที่หน้าแรกของโปรแกรม)

## คำถามที่พบบ่อย

**เปิดโปรแกรมแล้วจอขาว/ค้าง** — มีโปรแกรมนี้เปิดค้างอยู่อีกชุดหนึ่ง ปิดให้หมดใน Task Manager
(หา `node.exe` และ `electron.exe`) แล้วเปิดใหม่

**เสกของแล้วไม่ขึ้นในเกม** — ผู้เล่นที่ระบุต้อง**ออนไลน์อยู่ในเซิฟเวอร์ขณะนั้น** และชื่อ/SteamID
ต้องตรงกับที่โชว์ในเซิฟเวอร์จริง

**RCON เชื่อมต่อไม่ได้ / ขึ้นสถานะแดง** — รหัส RCON ในแท็บตั้งค่าไม่ตรงกับเซิฟเวอร์ที่กำลังรันอยู่
ลองกด **"รีสตาร์ทเซิฟเวอร์"** หนึ่งครั้ง

**คำสั่ง God Mode / โหมดบินกดแล้วไม่มีผล** — คำสั่งกลุ่มนี้ทำงานกับ "ตัวละครที่พิมพ์คำสั่งเอง"
เท่านั้น ต้องเข้าเกมแล้วกด **F1** พิมพ์เองในเกม สั่งผ่านหน้าโปรแกรมจากนอกเกมไม่มีผล

**Windows Defender / โปรแกรมแอนตี้ไวรัสแจ้งเตือน** — เกิดจากโปรแกรมยังไม่มีใบรับรองแบบเชื่อถือ
สาธารณะ (self-signed) ประกอบกับมีการดาวน์โหลดไฟล์อื่น (SteamCMD) และมีเทอมินอลในตัว ซึ่งเป็น
พฤติกรรมที่ heuristic ของ AV บางตัวอาจสงสัย ถ้ามั่นใจในแหล่งที่มา ให้ตั้งค่ายกเว้น (exclude)
โฟลเดอร์ที่ติดตั้งไว้

**ต้องมี Node.js ไหม** — ไม่ต้อง ตัวติดตั้งนี้รวมทุกอย่างที่จำเป็นไว้แล้ว ต่างจากการรันจากซอร์สโค้ด
