# Rust Server Manager

โปรแกรมจัดการเซิฟเวอร์ Rust แบบมีหน้าจอ (Windows เท่านั้น) — เปิด/ปิดเซิฟเวอร์, ตั้งค่าอัตราคูณ,
เสกไอเทม, จัดการปลั๊กอิน Oxide, สำรองข้อมูลแมพ และมีเทอมินอลในตัว

> repo นี้เก็บเฉพาะตัวติดตั้ง (.exe) ไม่มีซอร์สโค้ด

## ดาวน์โหลด

ไปที่แท็บ **[Releases](../../releases/latest)** ด้านขวา แล้วโหลดไฟล์ `Rust Server Manager Setup x.x.x.exe`

## วิธีติดตั้ง

1. ดับเบิลคลิกไฟล์ที่โหลดมา
2. Windows จะขึ้นเตือน **"Windows protected your PC"** — เป็นเรื่องปกติ (โปรแกรมนี้เซ็นด้วย
   self-signed certificate ยังไม่ได้ซื้อใบรับรองแบบเชื่อถือสาธารณะ) กด **"More info"** แล้ว
   **"Run anyway"**
3. ทำตามขั้นตอนติดตั้งจนจบ
4. เปิดโปรแกรม กด **ติดตั้ง/อัปเดต** เพื่อโหลดไฟล์เกม Rust ผ่าน SteamCMD (~6GB ใช้เวลา 5-15 นาที)
5. ไปแท็บ **จัดการแอดมิน & สิทธิ์** ใส่ SteamID64 ของคุณ แล้วกด **แต่งตั้งเป็น Admin**
6. กด **เริ่มเซิฟเวอร์**

> หา SteamID64 ได้ที่ [steamid.io](https://steamid.io)

## ข้อควรรู้

- รหัส RCON สุ่มใหม่อัตโนมัติทุกการติดตั้ง ดู/แก้ได้ในโปรแกรม
- หน้าเว็บจัดการทั้งหมด (รวมเทอมินอลในตัว) ผูกกับเครื่องตัวเองเท่านั้น เข้าจากเครื่องอื่นในวงแลนไม่ได้
- ปิดหน้าต่างโปรแกรม = ปิดเซิฟเวอร์ด้วย (บันทึกโลกให้ก่อนปิด)
- ต้อง forward พอร์ต **28015 UDP** ที่เราเตอร์ ถ้าจะให้เพื่อนเข้าจากนอกบ้าน
